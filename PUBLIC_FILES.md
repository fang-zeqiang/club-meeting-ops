# Public file review

Every tracked path belongs to one reviewed category:

- Root JavaScript, CSS, HTML, and `club-profile.js`: product runtime.
- `api/` and `server/`: same-origin API and persistence runtime.
- `test/`: fictional behavior fixtures only.
- `scripts/`: local checks and explicit Base maintenance commands.
- `docs/`: public setup, schema, changelog, demo data, and asset review.
- `.github/`: read-only CI and repository governance.
- `assets/branding/demo-club-mark.svg`: original reviewed demo artwork.
- Root metadata: license, contribution, security, package, Vercel, and README files.

Excluded from the snapshot: private notes, production operations docs, local
artifacts, existing screenshots, PDFs, spreadsheets, fonts, third-party marks,
member photos, QR codes, and the private repository's Git history.
